# Mizena Music Connector releases

This repository hosts versioned Windows Connector executables and their manifests for Mizena updates.

Each release uses a `connector-vX.Y.Z` tag and includes `mizena-music-connector-X.Y.Z.exe` plus `mizena-music-connector-X.Y.Z-manifest.json`. Mizena verifies the manifest and executable SHA-256 before activation.
